# 디자인 핸드오프 (pre-design 기준)

> [parcyun/pre-design](https://github.com/parcyun/pre-design)의 방향 확정 순서와
> [parcyun/authentic-web-design](https://github.com/parcyun/authentic-web-design)의 구현 기준을 따릅니다.

## 한 줄 브리프

**톤 재설정 + 첫 디자인 패스**: 휴대폰 홈 화면에서 매일 쓰는 개인용 할 일 앱을, 본인(교사)이 하루 동안 편하게 체크해 나가도록, **Soft Warm** 방향으로, 기존 구조를 지키면서 다듬는다.
완료 기준: 아래 "검증"의 항목이 실제 화면에서 통과.

## 핸드오프

| 항목 | 내용 |
| --- | --- |
| Intent | 하루를 시간대 칸으로 나눠 입력 순서대로 체크. 조용하고 부담 없는 화면 |
| Preserve | 칸 구성(일과전·일과중·이동중·일과후·언젠가), 타임라인 레일, 입력 순서 유지·시간순 정렬, 인라인 수정, 되돌리기, 드래그 정렬 |
| Change | 하늘색 배경 + 카카오 노랑 → 따뜻한 뉴트럴 + 점토색 포인트. 글꼴 이원화. 글자 기호(‹ › ✕ ⋮⋮) → 라인 아이콘. 중첩된 면 제거 |
| Direction | Soft Warm: 웜 화이트 바탕, 넉넉한 여백, 부드러운 반경, 그림자 없이 얇은 선 |
| Primary action | 할 일 `추가` (한 화면에 Primary는 이것 하나) |
| States | 기본 · hover · focus · active · disabled · 빈 상태 · 수정 중 · 완료 |
| Constraints | 모바일 우선(최소 360px), 다크 모드, `prefers-reduced-motion` 존중, 터치 대상 40px 이상 |

### 글꼴

| 역할 | 글꼴 | 굵기 |
| --- | --- | --- |
| 디스플레이(날짜, 칸 이름) | Gowun Batang | 700 |
| 본문·컨트롤 | Pretendard Variable | 400 · 600 |

크기: 13 · 16 · 20 · 28px (단계 사이 약 1.25배 이상)

### 간격·형태

- 간격: 4 · 8 · 12 · 16 · 24 · 32px (안쪽 여백 ≤ 바깥 여백)
- 반경: 컨트롤 10px, 면 14px, 칩·알약 999px
- 그림자 없음. 구분은 1px 선. 예외: 되돌리기 알림 하나
- 애니메이션: `transform`·`opacity`만, `cubic-bezier(0.25, 1, 0.5, 1)`

### 아이콘

[Lucide](https://lucide.dev) (`lucide-react`)만 사용. 이모지를 아이콘으로 쓰지 않음.

실제 화면에서 확인할 것:
1. 360px 폭에서 제목과 아이콘 버튼이 겹치거나 줄바꿈이 어색하지 않은가
2. Tab 키로 이동할 때 focus 표시가 보이는가
3. 아주 긴 할 일 문구, 할 일이 하나도 없는 날
4. 다크 모드 전환
5. 드래그 정렬이 터치에서도 되는가
