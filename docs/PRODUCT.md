# 제품 정의: 할일 관리

## 목적

일정이 날마다 달라지는 초등교사의 하루를 **시간 기준**으로 쪼개어, 입력한 순서대로 하나씩 체크해 나가는 개인용 할 일 앱.
(카톡 "나에게 보내기"로 '학교에서 / 퇴근 후 / 집 가서'를 적던 습관에서 출발)

## 핵심 개념

- **칸(구분)**: 근무일은 `일과전 · 일과중 · 이동중(퇴근길 등) · 일과후`, 쉬는 날은 `오늘 할 일` 한 칸. 모든 날 공통으로 `언젠가` 칸이 있음.
- **쉬는 날 모드**: 쉬는 요일(기본 일·토)은 자동으로 쉬는 날 모드. 날짜별로 수동 전환 가능.
- **입력 순서 = 할 순서**: 시간이 있는 일끼리만 시간순 정렬, 시간 없는 일은 입력 자리 유지.
- **체크하면 줄 긋기**.

## 기능 목록 (기존 아티팩트 기준)

| 구분 | 기능 | 단계 |
| --- | --- | --- |
| 기본 | 날짜 이동(어제/오늘/내일), 진행률 막대 | ✅ 뼈대 구현 |
| 기본 | 칸 선택하여 할 일 추가, 체크, 삭제, 선택 시간 입력 | ✅ 뼈대 구현 |
| 기본 | 근무일/쉬는 날 칸 구성 | ✅ 뼈대 구현 |
| 편집 | 항목 수정, 칸 이동, 드래그 정렬 | 1단계 |
| 편집 | 삭제 후 되돌리기 | 1단계 |
| 언젠가 | 언젠가 칸 + "오늘로 가져오기" | 1단계 |
| 세부 항목 | 하위 항목, 공부 항목은 ○ △ ✕ 표시 (그 외는 ○ ✕) | 2단계 |
| 반복 | 루틴(요일별 반복) 자동 추가 | 2단계 |
| 달력 | 월간 보기, 할 일 있는 날 표시 | 2단계 |
| AI | 하루 체크리스트를 보고 한 일·남은 일을 짚어주는 '오늘의 한마디' (선택 기능, 끌 수 있게) | 3단계 |
| 서비스화 | 로그인 · 서버 저장(기기 간 동기화) | 3단계 (필요 시) |
| 모바일 | PWA 설치, 오프라인 | 3단계 |

## 설계 메모

- 저장소는 `Storage` 인터페이스(`src/types.ts`) 뒤에 숨겨 두었음 → localStorage에서 서버 DB로 바꿀 때 화면 코드는 그대로.
- 하루 단위 문서(`DayDoc`)를 날짜 키로 저장: `todo-manager:day:YYYY-MM-DD`.
- 색상/글꼴 등 디자인 토큰은 `src/styles.css`의 CSS 변수에 모아 둠 (다크 모드 지원).
